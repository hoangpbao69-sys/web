Dán văn bản vào trang giấy bên dưới, chọn một trong 30 giọng đọc — mỗi giọng mang tên một ngôi sao hay hành tinh — rồi để công cụ tự chia đoạn, tự xoay vòng API Key và ghép lại thành một file MP3 hoàn chỉnh. Mọi thứ chạy ngay trong file HTML này, không cần server.

Bản thảo

Dán hoặc tải lên nội dung cần đọc. Không giới hạn độ dài — công cụ tự chia nhỏ và không làm rơi mất một ký tự nào.

0 ký tự ~0 đoạn sẽ được gửi đi

Chọn giọng đọc

Tên giọng chỉ quyết định chất giọng — ngôn ngữ đọc ra luôn khớp với văn bản bạn dán vào.

API Key

Key chỉ nằm trong bộ nhớ của trang này (không lưu lại, không gửi đi đâu ngoài Google) — đóng hoặc tải lại trang là mất, cần dán lại. Trình duyệt sẽ gọi thẳng đến API của Google bằng key này.

⚠️ Vì đây là 1 file HTML chạy trên máy bạn, key sẽ hiện ra trong tab Network của trình duyệt khi tool chạy — đừng mở file này trên máy tính công cộng hoặc chia sẻ file đã dán sẵn key cho người khác.

Tải file MP3 về máy
Về API Key: mỗi key có thể bị giới hạn quota theo ngày. Dán nhiều key (mỗi dòng 1 key) để tool tự xoay vòng khi 1 key bị hết hạn mức. Lưu ý: nếu trình duyệt chặn yêu cầu gọi Google API do CORS khi mở file trực tiếp (đường dẫn bắt đầu bằng file://), hãy chạy 1 server tĩnh đơn giản rồi mở qua http://localhost, ví dụ: python -m http.server trong thư mục chứa file này.
